# powerlink-comp

**powerlink-comp** — это open-source интеграционный мост между LinuxCNC и сервоприводами POWERLINK (CiA402).

Проект расширяет возможности применения высоконадёжных промышленных приводов в гибких open-source системах управления, позволяя использовать передовую аппаратную базу в кастомных решениях автоматизации.

## Совместимость
Компонент спроектирован для работы с любыми сервоприводами POWERLINK, реализующими стандартный профиль CANopen CiA402. В их числе:
* Сервоприводы **B&R ACOPOS** всех серий
* Контроллеры движения сторонних вендоров с поддержкой стандартов Ethernet POWERLINK (EPSG DS 301)
* Модули удаленного ввода-вывода и сопутствующая периферия

## Области применения
* **Модернизация станков с ЧПУ (Retrofit):** Вторая жизнь для существующих станков путем замены проприетарного верхнего уровня управления (ПЛК) на гибкую систему LinuxCNC без демонтажа дорогостоящих приводов и моторов.
* **Интеграция POWERLINK-экосистем:** Бесшовная связь промышленного openPOWERLINK-трафика с интерфейсом общей памяти (Shared Memory) LinuxCNC.
* **Исследования и прототипирование:** Быстрая отработка алгоритмов управления движением в области робототехники и промышленной автоматизации.

## Лицензирование
Проект использует гибридную модель лицензирования для максимальной гибкости:
* **HAL-компонент (`powerlink.comp`):** Распространяется под лицензией **GPLv2** (в силу требований линковки с внутренним API LinuxCNC).
* **Утилиты и эмуляторы (`tools/`, `plk_sim.c`, `shm_proto_test.c`):** Распространяется под лицензией **MIT**. Вы можете свободно использовать, модифицировать и интегрировать эту часть кода в свои коммерческие и закрытые продукты.
