# Clean Room Architecture / Архитектура «Чистой комнаты»

Проект Powerlink архитектурно разделён на два независимых слоя.
Это разделение обеспечивает юридическую чистоту кода, публикуемого
в открытом репозитории, и защищает интеллектуальную собственность
изготовителей промышленного оборудования и Заказчика.

---

## Слой 1. Открытый «движок» (Open-Source Engine)

**Находится в этом репозитории.** Написан с нуля, использует только
открытые спецификации и публичные примеры.

### Состав

| Компонент | Назначение |
|-----------|-----------|
| `comp/powerlink.comp` | HAL-компонент LinuxCNC. Читает/пишет данные через POSIX shared memory. Работает с абстрактным приводом (скорость, позиция, ошибки) — никакой привязке к конкретной модели. |
| `comp/powerlink_shm.h` | Контракт shared memory (структуры данных, размеры PDO). |
| `tools/plk_sim.c` | Эмулятор демона openPOWERLINK для офлайн-тестов. |
| `tools/shm_proto_test.c` | Self-test упаковки/распаковки PDO. |
| `configs/test_mn.*` | Примеры конфигураций для эмулятора (не содержат данных конкретного станка). |

### Используемые открытые спецификации

- **Ethernet POWERLINK** — EPSG DS 301, открытый стандарт (публичная спецификация).
- **CANopen CiA402** — профиль привода (открытая серия CiA).
- **POSIX shared memory** — механизм IPC. 

PDO-раскладка (PReq 54 Б, PRes 84 Б) основана на:
- открытом профиле привода **CANopen CiA402** (statusword, controlword,
  actual-position, actual-velocity, actual-torque — стандартные объекты
  0x6041/0x6040/0x6064/0x606C/0x6077 с типовыми размерами u16/s32);
- формате кадров Ethernet POWERLINK по EPSG DS 301.
Точные размеры PReq/PRes (54/84 Б) и резервные области являются
параметрами интеграции (задаются в XDD-описании конкретного привода
или техническом задании интегратора).

Код реализован по открытым стандартам без использования закрытых
материалов производителей. Снятие сетевого трафика с шины для целей
разработки этого кода не применялось.

### Лицензирование

- `comp/powerlink.comp` — **только GPL-2.0-or-later** (в силу линковки
  с GPL-библиотеками LinuxCNC: HAL, RTAPI). Предоставление на
  проприетарных условиях невозможно; «снятие GPL» не предлагается.
- Утилиты `tools/plk_sim.c`, `tools/shm_proto_test.c` — авторский код
  исполнителя. Публичное распространение под GPLv2; по запросу доступна
  **двойная (коммерческая) лицензия** для встраивания в закрытые
  продукты (по отдельному договору, через ИП/ООО — вне рамок НПД).

## Слой 2. Специфика станка Заказчика

**НЕ входит в этот репозиторий.** Передаётся Заказчику напрямую.

### Что входит в этот слой

- XDD-описание конкретного привода (XML-профиль устройства, поставляется
  его изготовителем вместе с изделием).
- Параметры и конфигурационные данные привода, предоставленные Заказчиком
  (снимаются с его собственного оборудования средствами Заказчика).
- Карты PDO, точные параметры двигателей (C_motor, SCALE).
- IP-адреса, node-ID, MAC-адреса сетевых устройств.
- Прочие данные, идентифицирующие конкретный станок.

### Правовой режим

Эти данные:
1. Являются собственностью изготовителя оборудования или Заказчика.
2. Включаются в состав распространяемых результатов НИОКР только
   по явному согласованию с правообладателем.
3. Не подлежат публикации в открытом репозитории.

Заказчик получает их вместе с актом приёма-передачи прав как
неотъемлемую часть технической документации на свой станок.
